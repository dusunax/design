# moa

에이전트 UI를 위한 경량 React 부품 모음이다. 부품 이름과 prop은 A2UI v1.0 basic catalog를 따른다.

## 시작하기

1. 설치한다.

   ```bash
   pnpm add @dusunax/moa
   ```

2. 앱 진입점에서 스타일을 한 번 불러온다. Tailwind가 없어도 된다.

   ```tsx
   import "@dusunax/moa/styles.css";
   ```

3. 부품을 쓴다. 부품마다 따로 불러올 수도 있다.

   ```tsx
   import { Button } from "@dusunax/moa";
   import { TextField } from "@dusunax/moa/text-field";

   <Button variant="primary">보내기</Button>;
   ```

## 다크 모드

감싸는 요소에 `data-moa-theme="dark"`를 붙인다. 그 안의 부품이 모두 dark 토큰으로 바뀐다.

```tsx
<div data-moa-theme="dark">…</div>
```

## 이 문서 둘러보기

| 사이드바 | 내용 |
|---|---|
| Foundations | 색, 글자 크기, 둥글기 토큰 |
| Layout | Row·Column, Card, List, Divider |
| Display | Text, Icon, Image |
| Actions | Button |
| Inputs | TextField, CheckBox, DateTimeInput |

부품마다 스토리가 두 개 있다.

- **Playground**: 아래 Controls 패널에서 prop을 바꿔 보는 곳이다.
- **Variants**: 주요 상태를 한 화면에 모은 곳이다. 테두리 상자 안이 부품이고, 상자 아래 회색 코드가 그 예시를 만든 prop이다.

화면 위 툴바의 Theme에서 light와 dark를 바꿔 볼 수 있다.
